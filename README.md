# JIT-Atlas

*the side quests that turn out to be critical*

Interactive, single-file HTML quests that model software systems as navigable flows: what runs where, what crosses each boundary, and where the common failures come from. Open one at the wall you just hit.

**Browse the catalogue: https://jit-atlas.github.io/**

## Layout

- `index.html`: the catalogue: campaigns first, then every quest by domain and subcategory.
- `quests/<slug>.html`: one self-contained quest per file, whether a standalone side quest or a mission in a campaign. Paths are permanent; a new version replaces the file at the same URL.

The site is plain, hand-maintained HTML with no build step.
