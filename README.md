# JIT-Atlas

*the side quests that turn out to be critical*

Interactive, single-file HTML Side quests that model software systems as navigable flows: what runs where, what crosses each boundary, and where the common failures come from. Open one at the wall you just hit.

**Browse the catalogue: https://jit-atlas.github.io/**

## Layout

- `index.html`: the catalogue, by domain and subcategory.
- `side-quests/<slug>.html`: one self-contained Side quest per file. Paths are permanent; a new version replaces the file at the same URL.

The site is plain, hand-maintained HTML with no build step.
