What happens when
you run next build

One command kicks off a long, ordered pipeline: load config, find every route, compile your TypeScript and JSX with Rust-based tooling, trace the module graph, prune dead code, split it into chunks, minify, and pre-render pages to HTML. This is a precise tour of every stage — top to bottom, in execution order.
