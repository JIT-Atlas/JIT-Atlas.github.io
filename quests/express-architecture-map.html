01 — Lifecycle

One request, top to bottom.

A request enters Node's HTTP server and is handed to app — which is literally a function. From there it descends through app.handle() into the router, gets matched against a stack of Layers, dispatched to a Route, and finally answered by a handler calling res.send(). Click any node.
