Complete Mental Model

The complete picture, collapsed into a scannable reference.

JS Layer
fetch() is called — JS thread
WebIDL
Maps JS call → C++ safely. Defines and return types.
C++ Fetch
CORS, headers, credentials, caching — all resolved natively
Network Stack
DNS → TCP → TLS → HTTP framing — all off the main thread
Node.js
libuv receives bytes → HTTP parser → IncomingMessage + ServerResponse streams
Response
Response travels back, browser parses headers → Promise resolves as microtask
JS Resumes
.then() callbacks run — body is still a stream, consumed asynchronously
fetch() is a JS API, implemented in native code, backed by WebIDL, executed by a browser networking stack, fulfilled via Promises, and ultimately handled by Node.js as streams through IncomingMessage and ServerResponse.
