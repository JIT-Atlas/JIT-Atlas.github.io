__next_f is not a JavaScript built-in. It is a custom global property created by Next.js. The name roughly means:

3 · What is push?

push is the normal JavaScript array method. Example:

So self.__next_f.push([1, "some payload"]) means append this Flight chunk to the __next_f array. In ordinary JavaScript terms, self.__next_f.push([0]) adds the item [0] to the end of the array self.__next_f.

4 · Read the whole expression slowly

This line does two jobs: (1) make sure self.__next_f exists, and (2) push the first chunk into it.

The parentheses matter: (self.__next_f = self.__next_f || []) returns the array; then .push([0]) pushes into that array. In words: “Use the existing Next Flight array if it already exists. If it does not exist, create an empty array. Then push [0] into it.”

5 · Why not just const __next_f = []?

Because each inline <script> tag is separate. Your HTML has many chunks like this — and each script needs access to the same shared place:

So Next puts the shared place on the global object. That way, every script tag can say self.__next_f.push(...) and they are all pushing into the same queue.

6 · Why does Next do this?

Because the HTML response is streamed. The browser can start receiving and parsing the page before the whole response is complete. So Next can send the page in pieces, and the inline scripts act like little delivery packets:

As soon as the browser reaches one, it runs it and stores the chunk. So the browser does not need to wait for one giant JSON file at the end.
