01 — THE MAP

One program, two computers

A web app is one program split across a server chip and a client chip, joined by a single network wire. The build compiles once and splits the graph at the 'use client' frontier; then one request traces the whole lifecycle — render down the server, cross the wire, paint and hydrate the client, and loop back on a Server Action. Trace weight shows what crosses: nothing from the server but data, the payload across, the heaviest JavaScript at hydration.
